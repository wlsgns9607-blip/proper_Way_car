반응형 웹 디자인

Bubble Mate는 모든 기기에서 완벽하게 작동하도록 설계되었습니다. 아래 탭을 통해 다양한 화면 크기에서의 레이아웃을 확인하세요.

문제 해결 & 기술 경험

문제:

소셜 로그인(Google, Naver, Kakao) 연동 시 리다이렉트 URI 보안 정책으로 인해 "Redirect URI mismatch" 오류가 발생했습니다. 로컬 개발 환경과 배포 환경에서 다른 도메인을 사용하면서 발생한 문제였습니다.

해결 방법:

Google Cloud Console, Naver Developer, Kakao Developer 각각의 설정을 분석하여 동적 콜백 라우팅을 구현했습니다. 환경 변수(.env)를 통해 개발/배포 환경을 자동으로 감지하고 올바른 콜백 URL을 설정하도록 JavaScript를 수정했습니다. 결과적으로 100% 안정적인 소셜 로그인이 구현되었습니다.

문제:

결제 시스템에서 Toss Payments API를 사용하려고 했을 때, 클라이언트 키와 시크릿 키 관리, 그리고 결제 검증 프로세스가 복잡했습니다. 또한 테스트 환경에서 실제 결제 플로우를 구현해야 했습니다.

해결 방법:

Toss Payments 공식 문서를 정독하고 API 명세를 분석했습니다. 서버 사이드에서만 시크릿 키를 사용하고, 클라이언트 사이드에서는 클라이언트 키만 사용하는 보안 구조를 설계했습니다. 테스트 모드와 실제 결제 모드를 환경 변수로 구분하여 관리하고, 결제 완료 후 서버에서 검증하는 로직을 구현했습니다.

문제:

PC, 태블릿, 모바일 등 다양한 기기와 브라우저(Chrome, Safari, Firefox, IE)에서 일관된 UI/UX를 제공해야 했습니다. 특히 모바일 환경에서 버튼 크기, 폰트 크기, 레이아웃이 깨지는 문제가 발생했습니다.

해결 방법:

Mobile-first 접근법을 채택하여 모바일부터 디자인을 시작한 후 상위 해상도로 확장하는 방식으로 변경했습니다. CSS Grid와 Flexbox를 적절히 활용하고, 미디어 쿼리를 세밀하게 조정했습니다. 또한 Autoprefixer를 사용하여 구형 브라우저 호환성을 확보했습니다. 결과적으로 모든 기기에서 완벽하게 동작하는 반응형 웹사이트를 구현했습니다.
